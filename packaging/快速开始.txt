美食地图 Foodie Trail — 快速开始
================================

一、怎么打开
------------
双击 FoodieTrail.exe。

  · 不会弹出黑窗口，几秒后浏览器会自动打开应用页面；
  · 窗口右下角（任务栏托盘）会出现一个橙色图钉图标，右键它可以看到：
      - 打开美食地图
      - 打开数据目录
      - 退出
  · 关闭浏览器不会退出程序；要真正退出，右键托盘图标选「退出」。

如果双击后浏览器没打开：右键托盘图标 →「打开美食地图」。
如果托盘里也没有图标：看 data\app.log 的最后几行。


二、你的数据在哪
----------------
就在 exe 旁边的 data\ 目录里：

  data\foodmap.db        记录与设置（SQLite）
  data\photos\           照片文件
  data\.fernet.key       加密钥匙（高德 Key 靠它解密）
  data\app.log           运行日志
  data\backups\          你手动放的备份

备份：把整个 data\ 目录复制走即可。
换机器：把 exe 所在文件夹 + data\ 一起拷过去。

注意：只拷 foodmap.db 而不拷 .fernet.key，已保存的高德 Key 会解不开
（记录和照片不受影响，重新填一次 Key 即可）。


三、第一次使用
--------------
1. 点「添加」，填店名 → 在地图上点一下位置 → 保存。
2. 右上角「更多 → 导出备份」可以随时备份。
3. 想要高德底图和地址搜索：右上角「更多 → 设置」里填 Key
   （只填 JS API Key 能出底图；地址搜索还需要单独一个「Web 服务 Key」）。
4. 不填 Key 也能正常用：底图走高德公开瓦片，只是不能搜地址、不能规划路线。


四、常见问题
------------
· 想换端口：默认每次自动挑一个空闲端口并记住（data\.last_port）。
  也可以在启动前设置环境变量 PORT=31200。
· 提示端口被占用：程序会自动换一个，不影响使用。
· 杀毒软件拦截：PyInstaller 打的 exe 偶尔会被误报，把整个文件夹加入信任即可。
· 卸载：安装版在「设置 → 应用」里卸载；卸载不会删除 data\，要彻底清空请手动删除。
· 这个程序只监听本机 127.0.0.1，手机或别的电脑访问不了，这是刻意的隐私设计。
